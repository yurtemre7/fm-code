# fm-code Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** A Swift CLI `fm-code` that writes a one-line Conventional Commit message (≤ 72 chars) for staged changes using Apple's on-device Foundation Models.

**Architecture:** Swift Package with a library `FMCodeCore` (pure logic + model glue) and a thin executable `fm-code`. The model gets one `GitTool` restricted to an enum of read-only git commands and returns a `@Generable` `CommitMessage`; Swift renders and enforces the 72-char limit.

**Tech Stack:** Swift 6.4, SwiftPM, FoundationModels, Swift Testing (`import Testing`), Foundation `Process`. No third-party dependencies.

**Spec:** `docs/superpowers/specs/2026-11-18-fm-code-design.md`

## Global Constraints

- Platform: `.macOS(.v26)`, Apple Silicon; no external dependencies.
- Output: exactly one line, `type(scope)!: subject`, max **72** chars, no body, no trailers, no trailing period.
- Types allowed: `feat, fix, docs, style, refactor, perf, test, build, ci, chore, revert`.
- Git is invoked as `/usr/bin/git` via `Process` with an argv array — never through a shell.
- The model may only run: `diff --staged`, `diff --staged --stat`, `status --short`, `log --oneline -n 10`.
- Tool output budget: **6000** characters, then `\n[truncated]`.
- rtk is optional: model tool calls use `rtk git <args>` when found, falling back to plain git on failure; `FM_CODE_NO_RTK=1` disables. Preflight, hook install and `git commit` never use rtk.
- Errors print to stderr and exit 1; the message alone goes to stdout.

## Review Focus

1. **Run from a subdirectory of the repo** — must work (git commands use the cwd; hook path from `git rev-parse --git-path hooks`). Test in Task 4.
2. **Repo with `core.hooksPath` set** — `--hook` installs into that path, not `.git/hooks`. Covered by using `rev-parse --git-path hooks` (Task 4 test).
3. **Hook during merge/amend/`-m`** — hook must do nothing when `$2` is non-empty. Test in Task 4 asserts the script content guards on `$2`.
4. **Model returns a subject with newlines, a trailing period, or Uppercase first letter** — sanitized to one clean line. Test in Task 1.
5. **Huge or binary diffs** — truncated to budget, never crash. Test in Task 2.

### Task 2: Read-only git runner

**Files:**
- Create: `Sources/FMCodeCore/Git.swift`
- Test: `Tests/FMCodeCoreTests/GitTests.swift`

**Interfaces:**
- Produces:
  - `public enum GitError: Error, CustomStringConvertible { case failed(String) }`
  - `public enum Git { static func run(_ args: [String], in dir: URL? = nil) throws -> String }` — `/usr/bin/git`, captures stdout; non-zero exit → `GitError.failed(stderr)`. Read stdout/stderr fully before `waitUntilExit` (avoid pipe deadlock on big diffs).
  - `public enum ReadOnlyGitCommand: String, CaseIterable, Sendable { case diff, diffStat, status, log }` with `var args: [String]` → `["diff","--staged"]`, `["diff","--staged","--stat"]`, `["status","--short"]`, `["log","--oneline","-n","10"]`.
  - `public func truncate(_ s: String, limit: Int = 6000) -> String`
  - `public func findRTK(env: [String: String] = ProcessInfo.processInfo.environment) -> URL?` — nil if `env["FM_CODE_NO_RTK"] == "1"`; else first executable `rtk` in `env["PATH"]` dirs, then `/opt/homebrew/bin`, `/usr/local/bin`.
  - `public struct ToolGitRunner: Sendable { init(rtk: URL?); func run(_ cmd: ReadOnlyGitCommand, in dir: URL) throws -> String }` — with rtk: run `rtk git <cmd.args>` (via `Process`, argv array); on non-zero exit or launch error fall back to `Git.run(cmd.args, in:)`. Without rtk: `Git.run`. Factor the `Process` plumbing so `Git.run` and the rtk call share it.

### Task 3: Model layer (GitTool + generator)

**Files:**
- Create: `Sources/FMCodeCore/GitTool.swift`, `Sources/FMCodeCore/Generator.swift`
- Test: `Tests/FMCodeCoreTests/GeneratorTests.swift`

**Interfaces:**
- Consumes: `CommitDraft`, `fit`, `render`, `Git.run`, `ReadOnlyGitCommand`, `truncate`.
- Produces:
  - `struct GitTool: Tool` — `name = "git"`, `@Generable struct Arguments { @Guide(description:, .anyOf(ReadOnlyGitCommand.allCases.map(\.rawValue))) var command: String }`; `init(cwd: URL, runner: ToolGitRunner)`; `call` maps rawValue → command (unknown → returns `"refused: not allowed"`), runs via `runner` in `cwd`, returns `truncate(output)` (empty → `"(no output)"`).
  - `@Generable struct CommitMessage { type: String (.anyOf CommitType raw values); scope: String?; subject: String; breaking: Bool }` + `var draft: CommitDraft` (unknown type → `.chore`).
  - `public func finalize(maxLength: Int = 72, draft: () async throws -> CommitDraft, retry: (Int) async throws -> CommitDraft) async throws -> String` — if `render(first).count <= maxLength` return it; else call `retry(render(first).count)` once; return `fit(second, maxLength:)`.
  - `public enum GeneratorError: Error, CustomStringConvertible { case modelUnavailable(String) }`
  - `public func generateCommitMessage(in dir: URL) async throws -> String` — checks `SystemLanguageModel.default.availability` (not `.available` → `modelUnavailable` with reason); session with `tools: [GitTool(cwd: dir, runner: ToolGitRunner(rtk: findRTK()))]` and instructions: write a Conventional Commit subject for the staged changes, call the git tool (start with `diffStat`, then `diff`; `log` for style), imperative mood, no body. Retry prompt: "Too long (N chars). Give a shorter subject, total ≤ 72 chars."

**Interfaces:**
- Consumes: `Git.run`, `generateCommitMessage(in:)`.
- Produces:
  - `public enum Command: Equatable { case print, commit, installHook, help }`; `public static func parse(_ args: [String]) -> Command?` — `[]`→print, `-c|--commit`→commit, `--hook`→installHook, `-h|--help`→help, else nil (usage + exit 1).
  - `public func preflight(in dir: URL) throws` — `rev-parse --is-inside-work-tree` fails → "not a git repository"; `diff --staged --quiet` exit 0 → "nothing staged". (Add `Git.succeeds(_:in:) -> Bool` for exit-code checks.)
  - `public func hookScript() -> String` — `#!/bin/sh`, `[ -n "$2" ] && exit 0`, then `msg=$(fm-code 2>/dev/null) && printf '%s\n' "$msg" > "$1"`; on failure leave file untouched.
  - `public func installHook(in dir: URL) throws -> URL` — dir from `git rev-parse --git-path hooks` (relative → resolve against `dir`), create dir if missing, refuse if `prepare-commit-msg` exists, write, chmod 0755.
  - `main.swift`: parse → preflight (except help/installHook) → print / commit flow: show message, prompt `Commit? [y]es / [e]dit / [n]o: `; `e` reads a replacement line (empty keeps original); `y` → `Git.run(["commit","-m",msg])`; prints errors to stderr with exit 1.

- Produces:
  - `public enum CheckStatus { case ok, warn, fail }` (symbols `[✓]`, `[!]`, `[✗]`)
  - `public struct Check: Equatable { status: CheckStatus; title: String; detail: String? }`
  - `public enum ModelState: Equatable { case available, deviceNotEligible, appleIntelligenceOff, notReady, other(String) }` + `static var current: ModelState` (maps `SystemLanguageModel.default.availability`)
  - `public struct DoctorInputs { macOS: OperatingSystemVersion; isAppleSilicon: Bool; model: ModelState; gitVersion: String?; rtkVersion: String?; repo: RepoState }` with `public enum RepoState: Equatable { case notARepo, nothingStaged, staged(files: Int, hookInstalled: Bool) }` and `static func gather(cwd: URL, env: [String: String]) -> DoctorInputs` (rtk version from `rtk --version`; staged count from `diff --staged --name-only`).
  - `public func checks(_ i: DoctorInputs) -> [Check]` — fail: macOS < 26, not Apple Silicon, model ≠ available, git missing. warn: rtk missing ("optional — install for more compact git output"), not a repo, nothing staged, hook not installed (detail: "run `fm-code --hook`").
  - `public func renderDoctor(_ checks: [Check]) -> String` — one line per check, then the "What the model can do" block listing `ReadOnlyGitCommand.allCases` args, then `No issues found!` if no fails, else `N issue(s) — fm-code can't run until fixed`.
  - Exit code: 1 if any `.fail`.
- Also: `--help` text ends with `Run 'fm-code doctor' to check your setup.`; startup errors (preflight, model unavailable) append the same hint.
